# Stats Mastery Public 📊

> Building a statistician — and an applied ML practitioner — completely in public.

**Who I am:** Undergraduate Statistics student at Begum Rokeya University, Rangpur (BRUR), Bangladesh. Working across statistical theory, data science, and applied analytics in R, Python, and Stata.

**What this is:** A permanent, structured, line-by-line public record of mastering statistics from first principles through to machine learning — full derivations, R/Python/Stata code, and self-tested Q&A at every tier (Basic → Core → Tricky → IQ → Viva → Research).
